# Roadmap

## GitHub Portfolio Assistant 1.0

La primera versión estable consolida el flujo principal de automatización del proyecto.

### Fundamentos

- [x] Arquitectura modular
- [x] Menú de consola
- [x] Gestión de proyectos locales
- [x] Ejecución centralizada de comandos

### Git

- [x] Consultar estado
- [x] Preparar cambios
- [x] Crear commits
- [x] Detectar remoto `origin`
- [x] Realizar push

### GitHub

- [x] Integración con GitHub CLI
- [x] Comprobar autenticación
- [x] Verificar repositorios
- [x] Crear repositorios
- [x] Publicar proyectos

### Análisis

- [x] Analizar estructura del proyecto
- [x] Detectar archivos principales
- [x] Detectar tecnologías
- [x] Analizar proyectos Python
- [x] Analizar notebooks Jupyter
- [x] Detectar bibliotecas utilizadas mediante reglas de análisis

### Documentación

- [x] Generar README inicial
- [x] Detectar README existente
- [x] Integrar generación de README en el flujo de publicación
- [x] Documentación de arquitectura
- [x] Changelog
- [x] Roadmap

### Seguridad

- [x] Detectar archivos sensibles
- [x] Detectar videos
- [x] Detectar modelos de IA
- [x] Detectar archivos de datos
- [x] Detectar archivos grandes
- [x] Comprobar protección mediante `.gitignore`
- [x] Advertir antes de publicar

### Automatización

- [x] Generar sugerencias de commit
- [x] Evitar commits vacíos
- [x] Configuración persistente
- [x] Confirmación configurable antes de push
- [x] Resumen previo a publicación
- [x] Flujo integral de publicación

### Validación

- [x] Pruebas funcionales de componentes
- [x] Compilación completa del proyecto
- [x] Prueba integral sobre un repositorio Git/GitHub
